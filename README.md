# SportsHub1 🏆

A modern sports web application built with React and TypeScript, designed to provide an interactive platform for exploring sports-related content and information.

## 🚀 Features

- Interactive sports-focused web interface
- Responsive and user-friendly design
- Organized sports content
- Reusable React components
- Service-based application structure
- Firebase integration
- AI-powered functionality using Google GenAI
- Fast and responsive Vite development environment

## 🛠️ Technologies Used

- React
- TypeScript
- Vite
- Firebase
- Google GenAI
- HTML5
- CSS3

## ⚙️ How to Run

### 1. Clone the repository

```bash
git clone https://github.com/radhakrishna-bandaru/SportsHub1.git
```

### 2. Open the project

```bash
cd SportsHub1
```

### 3. Install dependencies

```bash
npm install
```

### 4. Run the application

```bash
npm run dev
```
